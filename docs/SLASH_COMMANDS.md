# Okanvil — slash commands

Every command below is registered in the addon source; this file is generated by reading
the handlers, not from memory. Bare `/okanvil` (no argument) opens the window — most
module commands do the same, and only differ in which panel they focus.

Typing **`/okanvil help`** prints this list in-game.

## Where the output goes

Addon messages print to a dedicated **`Okanvil` chat tab** when that tab exists, and fall
back to your default chat frame otherwise. The tab is never created behind your back — a
raider who never opts in keeps seeing messages in General.

Create it once with **`/okanvil tab`** (it survives `/reload`; the client persists chat
windows). `/okdev` also creates it.

## Commands

| Command | Argument | What it does |
|---|---|---|
| `/okanvil` | *(none)* | Open / close the main window. |
| | `tab` | Create the dedicated `Okanvil` chat tab; all addon output moves there. |
| | `help` · `?` | Print this command list in chat. |
| `/okroll` | *(none)* | Toggle the mini roll manager (the small roll window). |
| `/okid` · `/idfind` | *(none)* | Open the window on the **ID Finder** module. |
| | `sweep` | Scan every currently-loaded item into the local ID database, then report the new total. |
| `/oklog` | *(none)* | Open the window on the **Combat Logs** module. |
| | `on` · `off` | Start / stop combat logging. |
| `/okrf` | *(none)* | Open the window on the **Raid Finder** module. |
| `/okrec` · `/recruit` | *(none)* | Open the window on the **Recruit** module. |
| | `on` · `off` | Enable / disable the recruiter. |
| | `afk` | Toggle AFK mode (auto-reply while away). |
| | `clear` | Wipe the whisper log. |
| | `toast` | Preview the recruit toast using your own name/class. |
| | `channels` | List the chat channels you are in, as `number = name`. |
| `/okdebug` | *(none)* | Toggle loot debug logging on/off. |
| | `tips` | **Backfill item tooltips** — ask the server for every drop that has no saved tooltip, re-scan it, and store the stat lines so the web export carries them. Run once before exporting to the hub. Only touches sessions you still have locally. |
| | `scan` | **Tooltips for the website.** Opens a paste box: give it the item ids the hub is missing (its *Copy missing ids* button), and it returns an `id -> tooltip` dictionary to paste back. Works even when the original sessions were deleted in game, because a tooltip belongs to the item, not to the drop. |
| | `log` | Open a copyable dump of the loot debug log (plus any silent errors, with repeat counts). |
| | `clear` | Wipe the loot debug log. |
| | `world` | Toggle open-world loot capture — lets you exercise the loot/award flow outside an instance. **Turn it off before real play** or world drops pollute the history. |
| `/okerr` | *(none)* | Show the persisted error log (copyable; survives logout). |
| | `clear` | Wipe the error log. |
| `/okdev` | *(none)* | Toggle dev mode. Debug output goes to the `Okanvil` chat tab (created if needed). |
| `/okfocus` | *(none)* | Emergency keyboard release — clears any edit box that trapped your keys. |

## Notes worth knowing

**`/okfocus` is the panic button.** If an edit box ever captures the keyboard mid-fight
and `W`/`A`/`S`/`D` stop moving you, this frees it.

**`/okerr` records even when you never asked.** Silent errors are always *recorded*, but
only *printed* when dev mode is on, and a repeated error at the same site prints once per
session (an error inside `OnUpdate` would otherwise print 60×/sec). So a bug that happened
mid-raid is still waiting for you afterwards.

**`/okdebug world` is a test mode.** It bypasses the raid/dungeon zone gate. Leave it off.

## For maintainers

Commands are registered as `SLASH_<NAME>1 = "/cmd"` plus `SlashCmdList["<NAME>"]`, spread
across:

- `Core/Core.lua` — `/okanvil`, `/okfocus`, `/okdev`, `/okerr`
- `Modules/IDs.lua` — `/okid`, `/idfind`
- `Modules/Logs.lua` — `/oklog`
- `Modules/Loot.lua` — `/okdebug`
- `Modules/LootRoll.lua` — `/okroll`
- `Modules/RaidFinder.lua` — `/okrf`
- `Modules/Recruit.lua` — `/recruit`, `/okrec`

`Okanvil:Print(msg)` is the single output funnel (~56 call sites). It resolves the chat
tab via `Okanvil:DevFrame(false)` on each call, so changing where messages land is a
one-function edit.

> **Careful with `|` in chat strings.** In WoW a bare `|` starts a colour escape
> (`|cAARRGGBB` … `|r`). Writing `(on | off)` in a `Print` truncates the line. Use `/` as
> a separator, or escape it as `||`.
